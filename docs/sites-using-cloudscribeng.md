# Sites using CloudscribeNG

We know from the usage statistics of our nugets and the Visual Studio Template that a *lot *of sites are using CloudscribeNG components in some way. It's always great to hear about specific examples so please [let us know](https://www.CloudscribeNG.com/contact) about your projects.

This is a curated list highlighting a few public websites that have told us they are using CloudscribeNG Core and/or CloudscribeNG SimpleContent.
